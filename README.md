# الحاوي — منصة تعليمية للدراسات والتاريخ

منصة عربية فيها صفحتان منفصلتان:

- صفحة المدرس: إضافة فيديوهات شرح الدروس وإدارة الامتحانات ومتابعة درجات الطلاب وإجاباتهم.
- صفحة الطالب (`/student.html`): إنشاء حساب خاص بالاسم والصف ورقم الهاتف، مشاهدة الشروحات، ودخول الامتحانات ومراجعة النتائج.

## تشغيل الموقع محليًا

1. ثبّت Node.js على الجهاز.
2. افتح مجلد المشروع في الطرفية وشغّل `npm install` لتثبيت اعتماد رفع الفيديو.
3. شغّل `npm start`.
4. افتح `http://localhost:4173` لإعداد حساب المدرس. يظهر رمز الإعداد لمرة واحدة في الطرفية.
5. افتح `http://localhost:4173/student.html` لصفحة الطالب.

## نسخة عرض مجانية على GitHub Pages

المستودع يحتوي على نسخة عرض ثابتة لا تحتاج إلى خادم أو رسوم استضافة. بعد تفعيل GitHub Pages من إعدادات المستودع باختيار الفرع `main` والمجلد `/ (root)`، شارك الرابط:
`https://youssef75r7r75r57.github.io/alhawy-exam-platform/`

تستخدم نسخة العرض بيانات تجريبية محفوظة محليًا في متصفح كل زائر، ولا تتصل بقاعدة البيانات الحقيقية. كود الامتحان التجريبي هو `HAWY26`. رفع وتشغيل الفيديوهات غير متاحين في النسخة الثابتة؛ استخدم إعداد Render أدناه لتشغيل خصائص الخادم.

## النشر على Render

ملف `render.yaml` يجهز خدمة Node.js في منطقة فرانكفورت، ويضيف مساحة تخزين دائمة للامتحانات والحسابات والنتائج وفيديوهات الشرح. يحتاج النشر إلى مستودع GitHub خاص مربوط بحساب Render.

1. أنشئ مستودعًا على GitHub وارفع ملفات المشروع إليه. اجعله خاصًا إذا لم ترغب في إتاحة الشيفرة للجميع. ملف `.gitignore` يستبعد قاعدة البيانات المحلية `.miyaar-data.json` ومجلد ملفات الفيديو `videos/` تلقائيًا؛ لا ترفع بيانات الطلاب أو ملفات الشرح إلى مستودع الكود.
2. في Render اختر **New → Blueprint**، واربط مستودع GitHub، ثم أنشئ الخدمة من `render.yaml`.
3. بعد اكتمال النشر افتح سجلات الخدمة في Render وانسخ `One-time teacher setup key`.
4. افتح رابط الموقع الذي ينتهي بـ `onrender.com`، وأدخل الرمز مرة واحدة لإنشاء كلمة مرور المدرس.
5. أرسل رابط الموقع للمدرس، وأرسل رابط `https://رابط-الموقع/student.html` للطلاب.

الخطة المستخدمة هي Starter مع مساحة تخزين دائمة 5 جيجابايت، لأن نسخة الاستضافة المجانية لا تحفظ الملفات بعد إعادة التشغيل. تقديرها الحالي نحو 8.25 دولار شهريًا (7 دولارات للخدمة و1.25 دولار للتخزين)، قبل الضرائب أو نقل الفيديوهات الإضافي. مشاهدة الطلاب للفيديوهات تستهلك نقل بيانات وقد تضيف تكلفة حسب الاستخدام والأسعار الحالية. ملف البيانات والفيديوهات يُحفظان داخل `/var/data`، وتبدأ الخدمة المنشورة دون حسابات طلاب أو امتحانات تجريبية.

### فيديوهات الشرح

- يرفع المدرس ملف MP4 أو WebM بحجم أقصى 800 ميجابايت، ويحدد عنوان الفيديو والدرس والصف.
- ينشئ الموقع كود مشاهدة عشوائيًا خاصًا بالفيديو. ينسخه المدرس ويرسله إلى الطلاب.
- يدخل الطالب إلى حسابه ويكتب الكود في صفحة الطالب لمشاهدة الفيديو داخل الموقع.
- ملفات الفيديو محفوظة على مساحة Render الدائمة، ومحمية عن العرض المباشر. سعة التخزين الحالية 5 جيجابايت، وتكفي نحو ستة فيديوهات بحجم 800 ميجابايت؛ زدها إذا احتجت إلى حفظ فيديوهات أكثر.
- كود المشاهدة يتحكم في الوصول للموقع، لكنه لا يمنع الطالب من تصوير الشاشة أو مشاركة الكود.

### نقل البيانات الموجودة على هذا الجهاز

قاعدة البيانات الموجودة في `.miyaar-data.json` تبقى على هذا الجهاز ولا تنتقل مع الكود. لذلك يبدأ الموقع المنشور بقاعدة مستقلة. لا ترفع ملف البيانات إلى GitHub؛ إذا احتجت نقل طلاب أو نتائج موجودة، انقل الملف مباشرة إلى مساحة الخدمة الخاصة بعد إنشاء الاستضافة.

### ملاحظات تشغيل

- احتفظ بالخدمة على نسخة تشغيل واحدة؛ مساحة التخزين الدائمة مرتبطة بنسخة واحدة من الخدمة.
- احفظ نسخة احتياطية من قاعدة البيانات ومجلد فيديوهات الشرح بانتظام.
- إعادة تشغيل الخدمة تنهي جلسات الدخول والمحاولات التي لم تُسلَّم بعد؛ النتائج المسلّمة محفوظة في قاعدة البيانات الدائمة.
- يجب أن يستخدم الطلاب والمدرس رابط HTTPS المنشور، وليس رابط `localhost`.
